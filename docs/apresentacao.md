# Liberages — Apresentação do Sistema

> *Uma plataforma digital construída para quem vive a vida liberal com segurança, discrição e prazer.*

---

## 1. O que é o Liberages?

**Liberages** é uma plataforma digital para o público liberal brasileiro — casais, solteiros e solteiras que praticam swing, troca, ménage, BDSM e outras formas de vivência sexual consensual entre adultos.

Mas Liberages **não é mais um site de encontros**. É uma **rede social com mapa interativo gamificado**, onde a descoberta de pessoas, locais e eventos acontece de forma espontânea, segura e divertida.

Pense no **Pokémon GO**, mas em vez de capturar criaturas, você descobre quem ao seu redor está a fim de uma aventura — e quais locais da sua cidade estão vivos com energia liberal今晚.

### Em uma frase:

> **Liberages é onde privacidade real, descoberta geográfica gamificada e uma comunidade verificada se encontram.**

## 2. Por que Liberages existe?

### O problema atual

O mercado de plataformas para o público liberal brasileiro é dominado por **um único player**: o Sexlog. Fundado em 2007, o Sexlog tem ~17 milhões de usuários cadastrados, mas sofre de problemas estruturais:

| Problema | Impacto |
|----------|---------|
| **Interface datada** | Parece um site dos anos 2000. Experiência mobile péssima. |
| **Privacidade frágil** | Sem blur facial, sem modo fantasma, sem proteção real contra prints. |
| **Sem mapa interativo** | Não existe forma de saber quem está perto de você ou quais locais estão ativos agora. |
| **Moderação insuficiente** | Perfis falsos, golpistas, sem verificação social. |
| **Preço elevado** | R$49,90/mês para um produto que não inova há anos. |
| **Sem app real** | Banido das App Stores. Site mobile-responsive com experiência inferior. |

### A oportunidade

- **20-30 milhões** de brasileiros têm interesse em vivências liberais.
- A **proibição de apps adultos nas lojas** (App Store / Play Store) abre espaço para **PWA** de alta performance.
- O público clama por **privacidade real** — não promessas vazias.
- Ferramentas modernas de **gamificação e geolocalização** podem transformar a experiência.

**Liberages nasceu para ocupar esse espaço.**

## 3. O Coração do Sistema: O Mapa-Radar

O mapa interativo é o **hub central** da experiência Liberages. Não é um recurso acessório — é o motivo pelo qual o usuário abre o app.

### Mapa de Locais

Um mapa interativo com marcadores por tipo de local:

- 🏠 **Casas de Swing** — pontos de encontro liberal
- 🛏️ **Motéis** — para encontros reservados
- 🍸 **Bares e Eventos** — pontos de encontro casual
- 🏖️ **Praias e Espaços** — ambientes naturais

O mapa começa com **50-100 locais curados por cidade** e cresce de forma colaborativa — a comunidade sugere novos locais, que são aprovados pela moderação.

### Radar de Atividade

Aqui é onde a magia acontece. O Radar mostra **atividade anônima** nos locais:

```
📍 Casa Fantasia
   👥 12 pessoas agora
   🔥 3 casais • 2 mulheres • 7 homens
   ⏰ Atividade alta nas últimas 2h
```

**Regra de ouro:** O radar **nunca revela identidades**. Você vê quantas pessoas estão em cada local, mas não quem são. A identidade só é revelada via chat privado, após consentimento mútuo.

### Check-in Dinâmico

Quando você faz check-in em um local, escolhe um **tempo de permanência** (TTL):

- ⏱️ 1 hora
- ⏱️ 2 horas
- ⏱️ 4 horas (máximo)

Quando o tempo expira, você **some do radar automaticamente**. Sem rastro, sem exposição involuntária.

### Destination Broadcast

Quer ir a algum lugar e está procurando companhia? Poste um **Destination Broadcast**:

> *"Vou pro Motel X hoje à noite, quem anima?"*

O post aparece no feed social, **expira após o evento**, e respostas são anônimas até que ambos combinem. Um convite informal, sem pressão.

### Login Rápido com PIN

Ninguém quer digitar e-mail e senha toda vez que abre o app. No Liberages:

1. **Primeiro acesso:** e-mail + senha (uma vez só)
2. **Dia a dia:** PIN de 4 dígitos (como app bancário)
3. **Rápido, seguro, discreto**

### Tipos de Conta

| Tipo | Descrição |
|------|-----------|
| **Solteiro(a)** | Conta individual |
| **Casal** | Conta compartilhada, um perfil público, login unificado |

> Nomes reais são **desencorrados**. A plataforma funciona com pseudônimos e apelidos. Sua identidade real é sua — não do público.

## 5. Privacidade Real — Não é Feature, é Direito

A privacidade no Liberages não é um botão escondido nas configurações. É a **camada fundamental** de tudo.

### Blur Facial Automático

Toda foto que você envia sobe com **blur automático no rosto**. Você escolhe, post a post, se quer revelar o rosto. Padrão: protegido.

### Modo Falso (Botão de Pânico)

Precisa esconder o app rápido? Um toque no **Modo Falso** e o app se transforma em:

- 🧮 Calculadora
- 🌤️ Previsão do tempo
- 📝 Bloco de notas

Ninguém ao seu lado sabe o que você estava usando. **Disponível para todos, grátis.**

### Modo Invisível e Fantasma

| Modo | O que faz | Quem vê |
|------|-----------|---------|
| **Invisível** | Se esconde de estranhos no radar e busca | Só amigos |
| **Fantasma** | Some completamente de tudo | Ninguém (exceto quem já tem contato) |

> Modos Invisível e Fantasma são **Premium** — porque privacidade avançada tem custo de infraestrutura.

### Selfie Destrutível

No chat privado, você pode enviar fotos que **se autodestroem após 1 visualização**. Abriu? Sumiu. Sem salvamento, sem rastro.

### Marca d'Água Dinâmica

Impossível bloquear prints em um PWA. Mas é possível **rastrear**. Toda foto renderizada embute um **hash invisível** do usuário que a está visualizando. Se vazar, o autor é identificado e **banido permanentemente**.

### Modo Anônimo em Comunidades

Nas comunidades, você pode participar com um **pseudônimo gerado** (ex: "Anônimo #4A7B"). Consistente dentro da comunidade — não muda a cada post. Moderadores veem a identidade real para garantir segurança; outros membros veem só o pseudônimo.

## 6. Gamificação que Engaja

Liberages usa gamificação **funcional** — badges e níveis não são cosméticos, eles **desbloqueiam permissões reais**.

### XP e Níveis

| Ação | XP Ganho |
|------|----------|
| Login diário | +5 |
| Postar no Fotolog | +10 |
| Postar no Fórum | +15 |
| Match | +50 |
| Check-in | +20 |

Níveis mais altos destravam features: mais swipes, bordas personalizadas, acesso a betas.

### Badges Funcionais

| Badge | Condição | Benefício |
|-------|----------|-----------|
| 🥉 Primeiro Check-in | Fazer primeiro check-in | Acesso básico |
| 🥈 Explorador | 5 locais diferentes | Reconhecimento social |
| 🥈 Borboleta Social | 10 matches | Mais visibilidade |
| 🥇 Veterano | 1 ano de conta | Status na comunidade |
| 🥇 Verificado | Confirmação de 4 amigos | Cria eventos públicos |
| 🥇 Cidade Inteira | 20 locais diferentes | Elite da plataforma |

### Moeda Única

Uma moeda virtual que unifica **tudo**:

```
         ┌──────────────┐
         │   COMPRA     │ ← R$ via Mercado Pago
         │   (Inflow)   │ ← Engajamento (check-ins, desafios)
         └──────┬───────┘
                │
         ┌──────▼───────┐
         │   MOEDA      │ ← Circuito fechado
         │  LIBERAGES   │ ← Sem cash-out, sem P2P
         └──────┬───────┘
                │
    ┌───────────┼───────────┐
    │           │           │
    ▼           ▼           ▼
 Match       Presentes   Descontos
 Boost       Virtuais    em Parceiros
```

- **Match Boost:** Destaque no swipe por 1h
- **Presentes Virtuais:** Emojis picantes no chat
- **Cupons B2B:** Descontos em casas de swing e motéis parceiros

> **Por que sem cash-out?** Porque transferir moeda virtual para reais exigiria compliance bancário (KYC pesado). Circuito fechado = zero atrito legal = operação enxuta.

## 7. Comunidade Verificada — Web of Trust

### O Selo Verificado

No Liberages, ser "verificado" não significa pagar. Significa ser **ocialmente confirmado**:

1. Você precisa de **4 amigos reais** que atestem que você existe fisicamente
2. Esses amigos precisam ter amizade classificada como `real` (conhecem você pessoalmente)
3. A verificação é **social e colaborativa** — não baseada em pagamento

> O selo Verificado libera privilégios como **criação de eventos públicos** e **acesso a comunidades exclusivas**.

### Moderação Híbrida

| Camada | O que faz | Quando |
|--------|-----------|--------|
| **IA (Robô)** | Triagem de fotos, detecção de spam, blur automático, rate limiting | Em tempo real |
| **Humana** | Decisão final em banimentos, revisão de denúncias, apelação | Assíncrono, em filas |

A IA **nunca age sozinha**. Toda sanção passa por um humano.

### Júri Popular

Para disputas comunitárias (não para denúncias individuais), usuários "Anjos da Comunidade" votam em regras e normas. Democracia interna, não punição arbitrária.

## 8. Conteúdo e Expressão

### Fotolog Diário

Uma foto por dia, estilo Fotolog clássico. Aparece no **feed social unificado** — um único scroll infinito sem abas.

**Ordenação do Feed:**
1. 👥 **Amigos** — sempre primeiro
2. 📍 **Pessoas próximas** — geolocalização
3. 🎯 **Alta compatibilidade** — fetiches em comum

Fotos expiram em **24h por padrão** (configurável: 24h, 7 dias, permanente).

### Álbuns

Galerias curadas com controle de privacidade:
- **Público** — todos veem
- **Só amigos** — apenas suas conexões
- **Só verificados** — apenas perfis confirmados
- **Privado** — só você

Free: até 3 álbuns. Premium: ilimitados.

### Contos Eróticos

Literatura criada por usuários. Free lê, Premium ou badges altos publicam.

### Swipe com Limites

Descoberta adicional via swipe — mas com **limites funcionais**:

| Tier | Limite diário |
|------|---------------|
| Free | 30 swipes |
| Premium | Ilimitado |

O deck de perfis é ordenado por: **1º Localização** → **2º Compatibilidade de fetiches**.

### Bucket List

Quebra-gelo inteligente: se você e outro usuário deram match e ambos querem ir ao **mesmo local**, o app sugere o encontro lá. Um "vamos juntos?" automático.

## 10. Como Funciona Tecnicamente

Para quem curte a parte técnica:

```
┌─────────────────────────────────────────────────┐
│                  LIBERAGES                       │
│                                                  │
│  ┌──────────────────────────────────────────┐   │
│  │          Single Binary Go                 │   │
│  │         (cmd/server/main.go)              │   │
│  │                                           │   │
│  │  ┌──────────┐  ┌──────────────────────┐  │   │
│  │  │ REST API │  │ BFF (serve React SPA) │  │   │
│  │  │ /api/v1/ │  │ + injeta configs      │  │   │
│  │  └──────────┘  └──────────────────────┘  │   │
│  │                                           │   │
│  │  ┌──────────┐  ┌──────────────────────┐  │   │
│  │  │ Service  │  │ SQLite + sqlc         │  │   │
│  │  │ (lógica) │  │ (SQL puro, sem ORM)   │  │   │
│  │  └──────────┘  └──────────────────────┘  │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  ┌──────────────────────────────────────────┐   │
│  │       React SPA + PWA (Vite)              │   │
│  │   Tailwind CSS + Glassmorphism            │   │
│  │   Service Worker + Manifest               │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│              Porta :3000 (única)                 │
└─────────────────────────────────────────────────┘
```

### Stack

| Camada | Tecnologia |
|--------|-----------|
| Linguagem | Go 1.26+ |
| HTTP | `net/http` stdlib |
| Banco | SQLite + sqlc |
| Frontend | React 19+ SPA + PWA |
| Estilo | Tailwind CSS v4 + Glassmorphism |
| Auth | JWT + bcrypt (interface trocável) |
| IDs | UUID v7 (server-generated) |
| Testes | Unit + Integration + API + E2E (Playwright) |

### Por que isso importa para você

- **Single binary** = um único arquivo, deploy trivial, custo de infra quase zero
- **PWA** = instala no celular sem App Store/Play Store (que banem apps adultos)
- **Desktop App** = system tray discreto, atalho de ocultação
- **SQLite** = escalate até ~50k usuários ativos sem complicação
- **Go** = performance nativa, memória eficiente, binário estático

## 11. O Que Não Faz (e Por Que)

Liberages é intencionalmente **enxuto**. Algumas features foram cortadas por segurança ou complexidade:

| Feature | Motivo do corte |
|---------|----------------|
| 🚫 Live Streaming | Custo de infra + moderação altíssimos |
| 🚫 Marketplace de Criadores | Não é o foco — rede social, não plataforma de conteúdo |
| 🚫 Carona Solidária | Liability física inaceitável |
| 🚫 GPS contínuo ("Tô Querendo") | Risco de triangulação e exposição |
| 🚫 Story 24h | Substituído pelo Fotolog (mais simples, mais elegante) |

> Cada feature cortada foi uma decisão **deliberada** para manter o produto focado, seguro e sustentável.
