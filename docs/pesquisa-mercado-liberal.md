# Pesquisa de Mercado — Plataformas Liberais Brasileiras

> **Data:** 25/07/2026
> **Objetivo:** Mapear o mercado real de plataformas para o público liberal/swing no Brasil, identificando players dominantes, gaps e oportunidades para o Liberages.
> **Fontes:** Acesso direto a sites (CRS No Fake, Casal Real, Feeld, SDC, Ysos, Club Desejos, SwingZone, HotSwingers, Swing.com.br), artigos de review (Redesocial18, Review Picante, Club Desejos, Casal Fetichista, Marie Claire).

---

## Resumo Executivo

O mercado de plataformas liberais no Brasil é **fragmentado e regionalizado**. Não existe um player dominante absoluto. As duas plataformas web mais utilizadas pela comunidade são o **Casal Real (CR)** e o **Casal Real Swing No Fake (CRS)** — ambas brasileiras, com presença consolidada e bases fiéis. O Sexlog, apesar de ter a maior base de cadastros (20M+), está em declínio por problemas de qualidade, segurança e interface. O Telegram se consolidou como o canal de comunicação informal mais usado.

**Conclusão-chave:** O Liberages não está entrando para competir com o Sexlog. Está entrando para resolver o que **nenhuma plataforma atual resolve** de forma integrada: verificação + mapa gamificado + comunidade + privacidade em camadas.

## 2. As Duas Plataformas Web Mais Usadas

**Site:** casalreal.com.br

| Item | Detalhe |

| **Região forte** | Rio de Janeiro (capital e Região dos Lagos), Minas Gerais, Espírito Santo |

**Características:**

- Permite cadastro de casais, solteiros e solteiras
- Perfil detalhado com fotos, preferências, desejos e limites

**Por que é popular:**
- Antiguidade e base fiel construída ao longo do tempo
- Acesso fácil, sem barreiras de aprovação
- Foca no mercado brasileiro com linguagem e cultura local
- Gera encontros presenciais via eventos listados na plataforma

### 2.2 CRS — Swing No Fake

**Site:** crsnofake.com

| Item | Detalhe |
|---|---|
| **Região forte** | São Paulo (capital e interior), Paraná, Santa Catarina, Rio Grande do Sul |
| **Modelo de acesso** | Restrito, cadastro com verificação |
| **Tagline** | "Credibilidade . Responsabilidade . Segurança" |
| **Acesso** | Exclusivo para membros aprovados |
| **Posicionamento** | Plataforma premium com foco em autenticidade |
| **Tecnologia** | ASP (Classic), orientação mobile |

**Características:**
- Plataforma que surgiu como resposta direta ao problema de perfis falsos
- Processo de cadastro mais rigoroso
- Verificação de identidade ativa
- Filtragem contra perfis inautênticos
- Modelo com assinatura/pagamento para acesso completo
- Interface funcional mas não moderna (ASP clássico)
- Foco em criar ambiente confiável

**Por que é popular:**
- Resolve o problema #1 do público liberal: **perfis falsos**
- O público de SP e Sul tende a ser mais seletivo e reservado
- Modelo premium filtra casualidades e curiosos
- Indicação boca-a-boca dentro da comunidade é forte

### 2.3 Diferencial CR vs CRS

| Aspecto | Casal Real (CR) | CRS No Fake |
|---|---|---|
| **Acesso** | Democrático, rápido | Restrito, verificado |
| **Verificação** | Menos rigorosa | Mais rigorosa |
| **Público** | Geral do meio liberal | Público que valoriza autenticidade |
| **Fakes** | Mais presentes | Filtragem ativa |
| **Cultura regional** | RJ (aberto, festivo) | SP/Sul (reservado, seletivo) |
| **Modelo** | Gratuito + premium | Assinatura necessária |
| **Tecnologia** | Web clássica | ASP clássico |

**Insight:** Juntas, CR e CRS cobrem praticamente todo o espectro do público liberal brasileiro — do mais acessível ao mais seletivo.

## 4. O Problema do Sexlog

O Sexlog tem a maior base de cadastros (20M+) mas **está sendo abandonado** pela comunidade. Razões:

| Problema | Impacto |
|---|---|
| **Interface "dos anos 2000"** | Lenta, ruim no mobile, desatualizada |
| **Perfis falsos e bots** | Erosão de confiança |
| **Paywall agressivo** | VIP, Premium, Diamond — sempre falta algo |
| **Sem verificação de identidade** | Qualquer um cadastra |
| **Profissionais do sexo** | Infiltração crescente |
| **Vazamentos de dados** | Já documentados |
| **Política de privacidade opaca** | Desconfiança |

**Ironia:** O Sexlog ainda é citado em reviews como referência, mas os usuários reais já migraram para CR, CRS e apps especializados. Ele sobrevive por inércia e massa de cadastros inativos.

## 5. Comportamento do Usuário Liberal Brasileiro

### 5.1 Perfil

- **Casais** são o público principal (80%+)
- Solteiros masculinos são maioria entre os não-casais, mas têm dificuldade de acesso
- Solteiras e mulheres bissexuais têm alta demanda
- Faixa etária predominante: 30-50 anos
- Classe média/média-alta (o lifestyle custa dinheiro)

### 5.2 Comportamento digital

- Usam **múltiplas plataformas simultaneamente** (tipicamente 2-3)
- **Telegram** é o canal de comunicação mais ativo
- Indicação boca-a-boca é o principal canal de descoberta
- Valorizam **privacidade** acima de tudo
- Buscam **eventos presenciais** — o app é ponte, não destino
- **Verificação de identidade** é a dor #1

### 5.3 Dores não resolvidas

1. **Perfis falsos** — problema crônico em todas as plataformas
2. **Falta de mapa/eventos** — nenhuma plataforma integra bem descoberta de eventos
3. **Privacidade** — medo de exposição é o maior bloqueador
4. **Interface ruim** — CR, CRS e Ysos têm interfaces ultrapassadas
5. **Fragmentação** — precisa usar 3-4 plataformas para ter cobertura completa
6. **Custo** — múltiplas assinaturas para ter acesso completo

| **Interface moderna** | Feeld (internacional) | Nenhuma BR oferece |
| **App + Web** | CR e CRS são web-only | Gap para mobile nativo |

### 6.2 Posicionamento sugerido

O Liberages não deve se posicionar como "alternativa ao Sexlog" ou "novo Casal Real". O posicionamento correto é:

> **"A única plataforma que combina verificação real, mapa de eventos e privacidade em camadas — feita para o público liberal brasileiro."**

### 6.3 Diferenciais competitivos

1. **Modo Guerrilha** — Custo operacional mínimo (R$33/mês) permite preço acessível
2. **Pix desde o dia 1** — Sem Stripe, sem barreiras de pagamento
3. **PWA + Desktop** — Funciona em qualquer dispositivo, sem depender de lojas de apps
4. **Mapa-radar gamificado** — Nenhum concorrente oferece
5. **Privacidade em camadas** — Controle granular de visibilidade
6. **Go backend** — Performance e segurança superiores às plataformas ASP legadas

## 9. Conclusão

O mercado liberal brasileiro é **grande, fragmentado e carente de inovação**. As plataformas dominantes (CR e CRS) são web legadas com interfaces dos anos 2000. O Sexlog está em declínio. Os apps brasileiros (Ysos, Club Desejos) têm boa base mas interface ruim. Os apps internacionais (Feeld, SDC) são melhores em UX mas têm base BR limitada.

**Nenhum combina:** verificação de identidade + mapa de eventos + gamificação + privacidade em camadas + interface moderna.

O Liberages tem uma janela de oportunidade real para entrar como a **primeira plataforma moderna e completa** para o público liberal brasileiro — não como mais um concorrente, mas como a evolução natural do mercado.
